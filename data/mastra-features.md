# Mastra Features & Capabilities

Mastra is a powerful TypeScript Agent Framework designed for building specialized AI systems.

## Key Features

1. **Agent Orchestration**: Easily define agents with specific personas, instructions, and toolsets.
2. **Tool Integration**: A robust system for creating and registering tools that agents can use to interact with the world.
3. **RAG (Retrieval-Augmented Generation)**: Built-in support for vector stores (like ChromaDB) and document processing to give agents access to custom knowledge.
4. **Persistent Memory**: Support for conversation history and observational memory to maintain context over long interactions.
5. **Streaming Support**: Real-time response streaming for responsive user interfaces.
6. **Workflows**: Capability to define complex multi-step processes and automated tasks.

## Why Use Mastra?

Mastra simplifies the process of building agentic systems by providing a unified workspace and a type-safe API for managing LLMs, memory, and tools.
