# Mastra RAG Test Document

Mastra is a powerful TypeScript Agent Framework designed for building autonomous systems and AI-powered applications.

Key features of Mastra:
- Modular Agent definitions.
- Integrated RAG with support for various vector stores like ChromaDB and Pinecone.
- Tool-calling and workflow orchestration.
- Built-in support for multiple LLM providers.

This document serves as a test file to verify the auto-indexing and retrieval capabilities of the RAG engine.
